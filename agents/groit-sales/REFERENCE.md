# Stock Clearance Operation - Reference Data

This file contains the specific operational context for the current deal. Skills provide the methodology. This file provides the facts.

## The Deal

Controlled redistribution of premium retail-grade surplus inventory from a major UK retailer.

- Authority confirmed legitimate
- Chain of custody confirmed
- Stock staged in London
- UK resale excluded
- France delayed from first wave
- ~102 tonnes
- ~533k units
- ~13.3m GBP retail value

## What This Is / Is Not

IS: Retail-grade surplus, structured category inventory, controlled access opportunity, professional transaction process.

IS NOT: Distressed stock, liquidation leftovers, marketplace dump inventory.

## Target Markets (First Wave)

Primary: Poland, Netherlands, Belgium, Germany, UAE
Secondary: Baltics, Balkans
Excluded: UK (resale), France (delayed)

## Ideal Buyer Profile

- Warehouse-backed
- Invoice-compliant
- Established apparel redistribution
- Export-capable
- Able to absorb volume
- Understands off-price inventory
- Fast commercial decision-making

## Buyer Types

Wanted: Off-price distributors, warehouse-backed wholesalers, export redistribution operators, institutional stocklot buyers.
Not wanted: Marketplace-heavy operators, online-only resellers, unverifiable companies.

## Transaction Flow (12 Steps)

1. Inventory intake
2. Category segmentation
3. Buyer qualification
4. NDA / controlled disclosure
5. Indicative pricing
6. Inspection
7. Offer negotiation
8. Contract
9. Secure payment milestone
10. Release
11. Export / logistics
12. Post-deal intelligence capture

## Mandatory Controls

- No uncontrolled disclosure
- No open blast lists
- No release before secure payment
- No invoice-free trading
- No unverified buyers
- No marketplace-heavy operators initially

## Information Release Stages

Stage 1 (Pre-qualification): High-level summary only. No brand, no quantities, no pricing, no photos.
Stage 2 (Post-NDA): Detailed categories, volumes, photos, commercial assumptions.
Stage 3 (Post-qualification + territory approval): Pricing, lots, inspection, contracts, logistics.

## Transaction Checklist (Gates)

Before Outreach: Inventory summary complete, documentation verified, buyer criteria finalized.
Before Disclosure: Buyer qualified, NDA signed, territory approved.
Before Offer: Inspection path agreed, commercial assumptions aligned, logistics path understood.
Before Release: Contract executed, secure payment milestone complete, export documents complete.
After Completion: Capture lessons, update buyer intelligence, update scoring model.

## Open Gaps (Do Not Fabricate Answers)

CRITICAL:
1. Resale restriction clarity (territory, online, marketplace, relabelling restrictions)
2. Commercial floor (minimum acceptable recovery, category expectations, lot structure)

HIGH:
3. Buyer approval governance (who approves buyers, disclosure, contracts)
4. Export & logistics workflow (warehouse process, release, shipping, inspection)
5. Payment structure (deposit, escrow/LC, release conditions, timeline)
6. Category segmentation (routing strategy, premium vs residual, bundles)
7. Buyer intelligence database (first 50 verified buyers, scoring, sequencing)
8. Legal pack (NDA, SPA template, compliance language, liability)

MEDIUM:
9. Inspection workflow (policy, evidence, samples, disputes)
10. Internal operating ownership (commercial, legal, logistics, buyer-approval owners)

## First 72 Hours Sprint

Day 1: Finalize restrictions, finalize commercial floor, finalize buyer criteria, build first 30-buyer list.
Day 2: Launch first-wave outreach, begin qualification calls, capture objections, validate category demand.
Day 3: Move strongest buyers into NDA process, prepare inspection path, align logistics, prepare pricing framework.

## Success Criteria

Commercial: Signed buyer, secure payment milestone, successful release, no leakage event.
Operational: Complete paperwork trail, clean export workflow, inspection process validated.
Strategic: Buyer intelligence captured, objections captured, pricing signals captured.
